# ⚡ SvitloChecker Ukraine

Акуратний та надлегкий монітор графіків відключень електроенергії для Windows. Розміщується прямо над панеллю завдань, не заважає роботі та вчасно попереджає про зміни у вашій черзі.

### ✨ Основні можливості
* **Підтримка операторів:** ДТЕК, YASNO та регіональні Обленерго.
* **Мінімалізм та швидкість:** Низьке споживання оперативної пам'яті та процесора.
* **Зручний інтерфейс:** Компактний індикатор над панеллю завдань або у системному треї.
* **Автооновлення:** Програма сама перевіряє наявність свіжих версій.
* ### 🔍 Підтримувані регіони та пошукові запити
Програма підходить для мешканців м. Київ та Київська обл. Одеська обл. Миколаївська обл. Дніпропетровська, 
Львівська, Івано-Франківська, Закарпатська, Тернопільська, Рівненська, Хмельницька обл. Харківська, Полтавська, Запорізька, Черкаська, Чернігівська, Житомирська обл. 


Використовуйте **SvitloChecker** як зручний:
* Віджет графіка відключень світла на робочий стіл Windows 10 та Windows 11.
* Індикатор черги відключень електроенергії (ДТЕК, YASNO, Обленерго) у треї.
* Настільний монітор наявності світла з таймером до наступного вимкнення або увімкнення.

---

### 📥 Як завантажити та встановити
1. Перейдіть у розділ **[Releases (Остання версія)](https://github.com/DEVMIHEY/SvitloChecker/releases/download/1.6/)**.
2. Завантажте файл `.exe` зі списку **Assets**.
3. Запустіть програму (встановлення не потрібне, працює одразу).
