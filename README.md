# ⚡ SvitloChecker Ukraine

Акуратний та надлегкий монітор графіків відключень електроенергії для Windows. Розміщується прямо над панеллю завдань, не заважає роботі та вчасно попереджає про зміни у вашій черзі.

### ✨ Основні можливості
* **Завжди під рукою:** акуратна капсула над треєм показує поточний стан та графік на 6 годин вперед (по кліку розгортається на повну добу, включно із завтрашнім днем).
* **Розумна підказка:** при наведенні курсора показує точний час найближчого відключення або увімкнення та зворотний відлік.
* **Автоматичні сповіщення:** капсула сама з’являється і блимає за 30 хвилин до відключення або при зміні графіка обленерго (присутні звукові налаштування).
* **Не заважає роботі:** автоматично ховається в іграх та повноекранних відео, має режим автоприховування, вибір регіону та черги.
* **Підтримка операторів:** ДТЕК, YASNO та регіональні Обленерго.
* **Мінімалізм та швидкість:** низьке споживання оперативної пам'яті та процесора, вбудоване автооновлення.

### 🔍 Підтримувані регіони та пошукові запити
Програма підходить для мешканців м. Київ та Київської, Одеської, Миколаївської, Дніпропетровської, Львівської, Івано-Франківської, Закарпатської, Тернопільської, Рівненської, Хмельницької, Харківської, Полтавської, Запорізької, Черкаської, Чернігівської та Житомирської областей.

Використовуйте **SvitloChecker** як зручний:
* Віджет графіка відключень світла на робочий стіл Windows 10 та Windows 11.
* Індикатор черги відключень електроенергії (ДТЕК, YASNO, Обленерго) у треї.
* Настільний монітор наявності світла з таймером до наступного вимкнення або увімкнення.
